## 🚀 Projeto em destaque

### 🏖️ [Vaktions — Sistema de Gestão de Férias e Funcionários](https://github.com/marioburali/vaktions)

Aplicação full stack desenvolvida para centralizar o gerenciamento de colaboradores e férias, transformando regras trabalhistas em fluxos e regras de negócio dentro do sistema.

**Stack**

`React` `TypeScript` `Material UI` `Vite`  
`Node.js` `Express` `Sequelize` `PostgreSQL`

**Principais implementações**

- Regras de negócio baseadas na CLT
- API REST com Node.js e Express
- Arquitetura em camadas utilizando MSC
- Modelagem e persistência de dados com PostgreSQL e Sequelize
- Autenticação e controle de acesso baseado em perfis
- Interface desenvolvida com React, TypeScript e Material UI

**Em desenvolvimento**

- Evolução da interface e experiência do usuário
- Ampliação da cobertura de testes
- Pipeline de CI/CD
- Deploy da aplicação para demonstração
